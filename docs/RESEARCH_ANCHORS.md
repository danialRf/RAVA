## FX examples
- Iranicard describes hourly-updated service rates for foreign-site payment:
  https://www.iranicard.ir/payments/
- Bonbast currently exposes open-market Iran FX data and an API product:
  https://www.bon-bast.com/

Do not hardwire the product to one FX provider before evaluating API terms, uptime, pricing, and business suitability.
